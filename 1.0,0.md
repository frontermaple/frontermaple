# FronterMaple

**Build inside Roblox Studio by chatting with ChatGPT.**

[![Version](https://img.shields.io/badge/version-1.0.0-blue)](../../releases)
[![License](https://img.shields.io/badge/license-GPL--3.0--or--later-green)](LICENSE)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS-lightgrey)

</div>

FronterMaple is a browser extension plus a small local bridge that lets the ChatGPT website work directly inside your open Roblox Studio place: read scripts, inspect instances, run Luau, edit code, generate models and more.

**No API key. No extra subscription.** You keep using the ChatGPT account you already have.

## ✨ Features

- **Works from the ChatGPT chat** - a FronterMaple bar sits above the composer; press Start and just talk.
- **Real, live access to Studio** - the AI runs commands in your place and reads the results by itself, step by step, until the task is done.
- **Clean chat** - raw commands are hidden and replaced by small status cards, so the conversation stays readable.
- **Project memory** - the AI keeps lasting notes about your game (where things live, conventions, decisions) in `ServerStorage.FronterMaple.Memory`, so every new chat already knows your project.
- **Safe by design** - the AI is instructed to confirm before deleting anything broad and to check before claiming Studio is offline.
- **100% local** - the bridge only listens on `127.0.0.1`; nothing leaves your machine except what you already send to ChatGPT.
- **Extendable** - other MCP servers declared in `config.json` are exposed to the AI next to Roblox Studio.

## 📋 Requirements

- Windows or macOS
- Roblox Studio with the **Studio MCP server** enabled (Assistant settings)
- A Chromium-based browser (Chrome, Edge, Brave...)
- Python 3 (on Windows, `start.bat` can help install it and the `websockets` library automatically)
- A ChatGPT account

## 🚀 Installation

### 1. Download
Download `FronterMaple.zip` from the [latest release](../../releases/latest) and **extract the whole folder** (don't run anything from inside the ZIP preview).

### 2. Start the bridge
- **Windows:** double-click `start.bat` and keep the window open.
- **macOS:** run `MacOS_Start.command` and keep the terminal open.

### 3. Install the extension
1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked**.
4. Select the `frontermaple-extension` folder.

### 4. Connect Roblox Studio
Open your place in Roblox Studio and enable the **MCP server** in the Assistant settings.

### 5. Start building
Open [chatgpt.com](https://chatgpt.com/), press **Start** on the FronterMaple bar above the chat box and describe what you want. For example:

> *"Create a pink part with particles in the Workspace."*

## 🧩 How it works

```
ChatGPT page ──(extension)──► ws://127.0.0.1:17614 ──► bridge.py ──► Roblox Studio MCP
      ▲                                                                   │
      └────────────────────────── results ◄───────────────────────────────┘
```

1. The extension reads the AI's replies and detects FronterMaple commands.
2. It sends them to the local bridge, which forwards them to the Studio MCP server.
3. The result goes back to the chat as the next message, and the AI keeps going on its own.

## 🛠️ Troubleshooting

| Problem | Fix |
| --- | --- |
| "Bridge or Studio offline" | Make sure `start.bat` / `MacOS_Start.command` is still running and Studio has a place open with the MCP server enabled. |
| The bar doesn't appear | Reload the extension in `chrome://extensions`, then refresh the ChatGPT tab (F5). |
| Commands stop after updating the extension | Refresh the ChatGPT tab (F5). |
| Studio MCP not found after a Studio update | Restart the bridge. If it still fails, set the `FM_STUDIO_MCP_PATH` environment variable to your `StudioMCP` executable. |
| ChatGPT stops accepting messages | You may have hit the free-tier limit; wait for the quota to reset. |

## 📁 Project structure

- `frontermaple-extension/` - the browser extension
- `bridge.py` - local WebSocket bridge
- `launch_studio_mcp.py` - finds the current Roblox Studio MCP executable
- `config.json` - MCP server configuration
- `start.bat` / `MacOS_Start.command` - launchers
